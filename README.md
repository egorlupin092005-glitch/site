## Что я умею

- **Поиск и сравнение.** Собираю информацию из открытых источников, выделяю критерии и свожу варианты в таблицу. Работаю с базовыми функциями Excel.

## Сайт портфолио

Статическая версия на HTML и CSS. Для просмотра откройте `index.html` из локальной копии репозитория. Для публикации через GitHub Pages в настройках **Pages** можно выбрать **Deploy from a branch**, ветку `main` и папку `/(root)`.

Превью взяты из репозиториев проектов. Изображение NFC-стоек на главной показывает примеры оформления.
